# Roadmap

Before public release: validate the latest Windows installer and the two-competition feed; test tray, notifications, startup, DPI, sleep/resume and monitor recovery on actual Windows installations; confirm live/halftime summary fields, UCL summaries and score corrections against real provider responses; and measure performance.

Review software licensing, data/crest permissions and installer signing before distribution. The app now covers the Premier League and Champions League; a properly licensed replacement provider and stronger offline recovery remain future improvements. Champions League live/halftime summaries and packaged runtime behavior still need verification. Off-screen window recovery now ships, but monitor removal, mixed-DPI setups and taskbar placement still need packaged Windows acceptance.

The [Match Centre evolution report](archive/MATCH_CENTRE_EVOLUTION_REPORT.md) records earlier checkpoints and current acceptance gaps. The [Windows checklist](VALIDATION.md) distinguishes CI from runtime verification.
